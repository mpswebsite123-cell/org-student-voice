# StudentVoice — GitHub Pages Demo

A responsive student-support reporting **concept demo** built with plain HTML, CSS and JavaScript. No build tools or backend are required.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `studentvoice`).
2. Upload `index.html`, `styles.css`, `app.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your URL will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Features
- Responsive StudentVoice landing page.
- Student demo portal with report creation and report history.
- Kerala district and category selection with simulated routing preview.
- Reference number generation and browser-local demo persistence.
- Agency demo case desk with search, sample cases and status updates.
- Privacy and service-boundary notices.

## Important safety and deployment notes
- This is a **demonstration prototype**, not an official school, government, police, or emergency reporting service.
- Reports are stored in the current browser's `localStorage`; they are not sent to a server or visible to another person/device.
- Use fictional information only. Do not enter real names, contact details, student IDs, passwords, or sensitive personal information.
- The agency view is a demonstration workspace and has no authentication. Do not use it for real cases.
- Do not claim guaranteed anonymity. A real deployment needs a security review, appropriate safeguarding policy, secure server-side authentication, access controls, encrypted transport and storage, audit logging, retention/deletion rules, and a responsible organization to monitor submissions.
- For immediate danger, contact a trusted adult or the appropriate local emergency service. Do not rely on this demo.

## Customization
Edit the text in `index.html`, styles in `styles.css`, and demo behavior/data in `app.js`.
